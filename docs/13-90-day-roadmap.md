# 13. 90-Day Launch Roadmap

**Overall goal for day 90:** at least **2 paying clients**, **1 Production Pilot delivered or in delivery**, **1 Run retainer agreed** (it's included in the Pilot SOW by default; billing starts after go-live), a working sales engine (repeatable outreach + 3 partners) and a reusable Delivery Kit v1.

Targets are **[Recommendation]**. Adjust them at each decision gate based on real data.

---

## Days 1–30: Foundation

**Phase objective:** validate the beachhead, become "open for business" credibly, and start warm-network selling by **week 3**. Don't wait for perfection.

| Week | Milestones | Outputs |
|---|---|---|
| **1** | Incorporate Ltd (if not done), business bank, accounting software, ICO fee, insurance quotes. Finalise name checks. **10 validation interviews booked** with ICP 1 (CTOs/COOs at SaaS companies): ask about AI attempts, pains, budgets, *not* a pitch | Company set up; name chosen; interview list |
| **2** | Hold 8–10 validation interviews. Lock the beachhead and the 4 launch offers + prices. Commission contract template pack (MSA/SOW/DPA/subcontractor). Start contractor search. Start **Demo Project 1** (AI support agent on a public help-centre dataset, with an eval report) | Interview synthesis (pains, words customers use, willingness to pay); offer sheet v1 |
| **3** | **Warm-network outreach to 50–100 contacts** (founding-client offer). Brand basics (wordmark, colours, type). LinkedIn profile rewritten; first 3 posts. Draft website copy. Build target list of 200 ICP 1 accounts with trigger signals | 50+ personal messages sent; LinkedIn live; list built |
| **4** | Website v1 live (Home, Sprint, Automation, Agents, How we work, About, Book). Demo Project 1 finished + write-up. Sales kit: 1-page offer PDF, Sprint sample output, proposal template, discovery script. Outbound sequences set up on a separate warmed domain. 2 contractors vetted with paid trials | Website live; demo published; sales kit; contractor bench started |

**KPIs by day 30**

| KPI | Target |
|---|---|
| Validation interviews held | ≥ 8 |
| Warm-network messages sent | ≥ 50 |
| Discovery calls booked (from any source) | ≥ 4 |
| Website + 1 demo project live | Yes |
| Contractors vetted | ≥ 2 |
| LinkedIn posts published | ≥ 9 |

**🚦 Decision gate (day 30)**
- **Go:** ≥ 5 of 8+ interviewees confirm the pain exists *and* they'd pay to fix it; ≥ 4 discovery calls booked → proceed with ICP 1 as primary.
- **Adjust:** pain is real but budgets weak → shift emphasis to ICP 2 (professional firms) or lead with Starter offers.
- **Stop/rethink:** interviewees don't see the problem as a priority → revisit segment before spending on outbound.

## Days 31–60: Market Entry

**Phase objective:** generate qualified pipeline through outbound, partners and content; **close the first paid engagement(s)**.

| Week | Milestones | Outputs |
|---|---|---|
| **5** | Start signal-based outbound: **50 new contacts/week**. Approach 10 software agencies and 5 VCs/accelerators. Publish first long-form insight ("Why AI pilots fail, and the 25-point production checklist") + lead magnet | Outbound running; partner pipeline |
| **6** | Discovery calls (target 3+). Start **Demo Project 2** (document extraction with field-level accuracy report). Apply for Cyber Essentials. Contract templates finalised | First Sprint proposals out |
| **7** | **Close first Sprint (target).** Deliver Sprint #1. Second agency/VC meetings. Co-host or book a first workshop/webinar with a partner | First invoice paid 🎯 |
| **8** | Convert Sprint #1 into a Pilot proposal. Continue outbound + content. Sign first agency partner (referral agreement). Build Delivery Kit v1 from demo code (template repo, eval harness, RAG/agent starters) | Pilot proposal; partner #1; Delivery Kit v1 |

**KPIs by day 60**

| KPI | Target |
|---|---|
| New outreach contacts (cumulative) | ≥ 200 |
| Discovery calls held (cumulative) | ≥ 10 |
| Proposals sent | ≥ 3 |
| Paid engagements signed | ≥ 1 (target 2) |
| Revenue invoiced | ≥ £3,500 (one Sprint) |
| Partners signed | ≥ 1 |
| Cyber Essentials | Submitted |

**🚦 Decision gate (day 60)**
- **Go:** ≥ 1 paid engagement and ≥ 10 discovery calls → scale outbound, keep the offer.
- **Adjust:** calls happening but no closes → review proposals and pricing with 2–3 prospects who said no; test the Starter Sprint price point or a narrower offer (e.g. "AI support agent pilot only").
- **Adjust channel:** < 6 calls → reply rate problem. Rewrite messaging using interview language, lean harder on partners and warm intros.

## Days 61–90: Growth

**Phase objective:** deliver excellently, turn delivery into proof, introduce recurring revenue, and systematise.

| Week | Milestones | Outputs |
|---|---|---|
| **9** | **Pilot #1 kicks off** (baseline captured, acceptance metric signed). Sprint #2 delivered. Outbound continues (never pause) | Pilot running; weekly demos |
| **10** | Pilot spike gate passed. First workshop delivered (with Sprint offer at the end). Second partner signed | Workshop leads |
| **11** | Pilot in build/harden. Draft case study #1 structure (permission agreed in contract). Refine service packages from what clients actually bought and asked for. Cyber Essentials achieved (target) | Updated offer sheet v2 |
| **12** | Pilot shadow mode. **Run retainer proposed** with live value dashboard. Ask for referrals. Document SOPs from real experience | Run proposal |
| **13** | Pilot go-live + acceptance (or week 14–15 if the client's data access was slow). **Run retainer starts.** Testimonial collected **with written permission**. 90-day review: finances, funnel conversion rates, founder load, next-quarter plan | Case study draft; Run MRR; Q2 plan |

**KPIs by day 90**

| KPI | Target |
|---|---|
| Paying clients | ≥ 2 |
| Revenue invoiced (cumulative) | £10,000–£20,000 (Sprint fees + Pilot deposit). The financial model's Realistic case is more cautious and recognises only ~£5k of *revenue* by month 3, so beating it is a positive signal |
| Pilots delivered or in delivery | ≥ 1 |
| Run retainers agreed | ≥ 1 |
| Weighted pipeline | ≥ £40,000 |
| Case studies (drafted, permissioned) | ≥ 1 |
| Partners signed | ≥ 2–3 |
| Sprint → Build conversion | Tracked (target ≥ 40%) |
| Founder load | ≤ 100%; contractor bench of ≥ 3 |

**🚦 Decision gate (day 90)**
- **Scale:** ≥ 2 clients, pipeline ≥ £40k, Run attached → raise prices 10%, add contract delivery lead when load triggers fire, double down on the best channel.
- **Focus:** 1 client, pipeline thin → narrow to the single offer that sold, the single channel that produced calls, and the single ICP that responded.
- **Pivot test:** 0 clients despite ≥ 15 discovery calls → the problem is offer or positioning, not activity. Run 5 "lost deal" interviews and test a different entry offer (e.g. governance sprint for professional firms, or "AI feature rescue" for SaaS).
