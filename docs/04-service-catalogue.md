## A. AI Strategy and Consultancy

### A1. AI Opportunity Sprint ⭐ flagship entry product
| | |
|---|---|
| **Customer problem** | "We know we should be using AI, but we don't know where it pays off, what to build versus buy, or what it will cost." |
| **Solution** | A time-boxed diagnostic. We interview stakeholders, map workflows, size each opportunity in £ and hours, check data readiness, and produce a ranked roadmap with a build-vs-buy recommendation for each item. |
| **Deliverables** | Opportunity register (5–10 scored use cases); value/feasibility matrix; recommended first pilot with scope, acceptance metric and fixed quote; build-vs-buy recommendations (including off-the-shelf tools where they win); risk and data-protection notes; 60-minute readout to leadership. |
| **Process** | Day 1 kickoff → Days 2–4 interviews and workflow shadowing, data sampling → Days 5–7 sizing and feasibility spikes (quick technical tests on real samples) → Readout. |
| **Duration** | Starter: 1 week (one function). Growth: 2 weeks (company-wide). |
| **Price** | £3,500 / £7,500. **100% credited against a Build signed within 30 days.** |
| **Outcomes measured** | Number of qualified opportunities, total sized annual value, decision made on first pilot within 30 days. |

### A2. AI Readiness & Governance Sprint
| | |
|---|---|
| **Customer problem** | Staff are already using public AI tools with company data. Leadership has no policy, no inventory and no view of the risk. |
| **Solution** | AI usage audit, risk assessment and a practical governance pack aligned with UK GDPR and ICO guidance (and EU AI Act exposure where relevant). |
| **Deliverables** | AI usage inventory; acceptable-use policy; data classification rules for AI; approved-tools list; DPIA template for AI projects; vendor due-diligence checklist; staff briefing session. |
| **Duration / Price** | 2 weeks. £5,000 (Growth) / from £12,000 (Enterprise, multi-entity). |
| **Outcomes measured** | Policy adopted; % staff briefed; shadow-AI tools moved to approved alternatives. |
| **Note** | This is governance advisory, **not legal advice**. We recommend clients' solicitors review policies. Partner with a data-protection lawyer for regulated clients. |

### A3. AI Transformation Roadmap & Technology Selection (Enterprise)
| | |
|---|---|

| **Solution** | Opportunity Sprint at scale + target architecture + model/vendor selection (with evaluation on their data) + operating model and governance design. |

## B. AI Automation

### B1. Workflow Automation Build (Starter)
| | |
|---|---|
| **Customer problem** | Staff spend hours a week copying data between systems, triaging emails and producing routine documents. |
| **Solution** | One end-to-end automated workflow combining an orchestrator (n8n by default) with LLM steps for classification, extraction and drafting, plus human approval where needed. |
| **Deliverables** | Working workflow in the client's accounts; error handling and alerts; run log; operator guide; 2-week hypercare. |
| **Duration / Price** | 3–4 weeks. £8,000–£15,000. |
| **Outcomes measured** | Hours saved per week (time-and-motion baseline vs after), error rate, volume processed. |

### B2. AI Customer Support Automation ⭐ most common Pilot
| | |
|---|---|
| **Customer problem** | Ticket volume grows faster than the team. Answers are inconsistent. First-response times slip. |
| **Solution** | AI support agent grounded in the help centre, past tickets and product docs, integrated with Zendesk/Intercom/Freshdesk/HubSpot. It starts in **draft mode** (agents approve replies), then moves to **auto-resolve** for categories that pass the evaluation threshold. |
| **Deliverables** | Retrieval pipeline over knowledge sources; agent with tool access (order lookup, account status) as scoped; evaluation set built from real historical tickets; escalation rules; dashboard (deflection, CSAT, cost per resolution); runbook. |
| **Duration / Price** | 6 weeks. £20,000–£40,000. |
| **Outcomes measured** | % tickets drafted / resolved, accuracy on eval set, first-response time, CSAT change, cost per ticket. |
| **Build-vs-buy note** | For standard help-desk use cases, off-the-shelf tools (for example Intercom Fin, Zendesk AI) may be cheaper. We say so in the Sprint and build only where workflows, data or integrations are non-standard. |

### B3. Document Processing Automation
| | |
|---|---|
| **Customer problem** | Invoices, contracts, applications, claims or CVs are read and keyed in by hand. It's slow, error-prone and doesn't scale. |
| **Solution** | Intake → classification → extraction to a schema → validation rules → human review queue for low-confidence items → push to the system of record. |
| **Deliverables** | Extraction pipeline; validation rules; review UI or queue; labelled test set and accuracy report by field; integration with ERP/CRM/DMS. |
| **Duration / Price** | 4–6 weeks. £12,000–£35,000. |
| **Outcomes measured** | Field-level accuracy, % straight-through processing, minutes per document, backlog. |

### B4. CRM & Business System Integrations
| | |
|---|---|
| **Customer problem** | CRM data is incomplete. Reps waste time on research and admin. Systems don't talk to each other. |
| **Solution** | AI enrichment, call/meeting summarisation to CRM, lead research and routing, automated follow-up drafts (human-sent). |
| **Duration / Price** | 3–6 weeks. £10,000–£30,000. |
| **Outcomes measured** | CRM completeness, rep hours saved, speed-to-lead, meetings booked. |

## C. AI Agent Development

### C1. Custom AI Agents (support, sales, research, operations)
| | |
|---|---|
| **Customer problem** | Multi-step tasks (researching an account, preparing a quote, reconciling records) need judgement plus tool use. Simple automations break on them. |
| **Solution** | Tool-using agents with tightly scoped permissions, deterministic guardrails, human-in-the-loop checkpoints for consequential actions, and full tracing. We use the **simplest architecture that works**: a single agent with good tools before a multi-agent system. |
| **Deliverables** | Agent service; tool/API integrations; permission model; approval UI; tracing and observability; evaluation suite (task success, tool-use accuracy, cost, latency); runbook. |
| **Duration / Price** | 6–10 weeks. £25,000–£60,000 (Growth); multi-agent / enterprise £60,000+. |
| **Outcomes measured** | Task success rate on eval set, % tasks needing human correction, time per task, cost per task. |

### C2. Internal Knowledge Assistant
| | |
|---|---|
| **Customer problem** | Answers are buried in Notion, Confluence, SharePoint, Drive and Slack. New staff take months to ramp up. Experts get interrupted all day. |
| **Solution** | Permission-aware retrieval assistant (respects source-system access controls) in Slack/Teams/web, with citations on every answer. |
| **Deliverables** | Connectors and ingestion pipeline; permission mapping; chat interface; citation and feedback capture; eval set from real staff questions; usage dashboard. |
| **Duration / Price** | 4–6 weeks. £15,000–£35,000. |
| **Outcomes measured** | Answer accuracy on eval set, weekly active users, questions deflected from experts, onboarding time. |
| **Build-vs-buy note** | Enterprise search products (for example Glean, Microsoft Copilot) can fit firms already deep in one ecosystem. We compare honestly. |

### C3. Agentic Workflow Systems / Multi-agent (Enterprise)
Scoped individually after a Sprint. Only proposed when a single-agent design has been shown to be insufficient.
