# Client onboarding and go-live checklist

## Contract and admin (day 0–2)

- [ ] MSA, SOW and DPA signed
- [ ] Setup deposit paid; Direct Debit mandate active
- [ ] Client record created (CRM, Notion delivery board, 1Password vault, Git folder)
- [ ] Welcome pack sent (contacts, timeline, onboarding form, access instructions, staff one-pager)
- [ ] Kick-off booked; champion named

## Discovery and baseline (week 1)

- [ ] Success plan KPIs confirmed in writing
- [ ] Baseline captured: call logs (2 weeks), response-time test, no-show rate (4 weeks), booking volumes, admin hours sample
- [ ] Customer journey mapped
- [ ] Escalation rules agreed (who, when, how, out-of-hours)
- [ ] "Never say or do" list agreed
- [ ] Content collected: services, prices, hours, policies, FAQs (top 30+), tone of voice, allergen matrix or other regulated content (verified by the client)

## Access (least privilege; never shared passwords)

- [ ] Booking, CRM or POS: user or API key with minimum permissions
- [ ] Phone provider: call forwarding or SIP configuration
- [ ] Website: widget installation access, or snippet sent to the web developer
- [ ] Meta Business Manager: WhatsApp Business Account, Instagram, Facebook
- [ ] Google Business Profile: manager access (for the review flow)
- [ ] Email (if automating): delegated access or app-specific integration
- [ ] Access log updated

## Compliance

- [ ] DPIA screening completed; full DPIA if required (`dpia-and-ai-risk-checklist.md`)
- [ ] Privacy notice wording provided for the client's website
- [ ] AI disclosure scripts approved (voice greeting, chat widget)
- [ ] Call recording and transcription notice included
- [ ] Marketing consent status confirmed for any campaign lists
- [ ] Sub-processors confirmed; data hosting region selected
- [ ] Retention period set (default 90 days)

## Build and test

- [ ] Built from niche template; client-specific config versioned in Git
- [ ] Evaluation set (30–50 real questions) passed at ≥ 95%, with zero critical failures
- [ ] Edge cases tested: angry customer, unsupported language, prompt injection, red-flag topics, out-of-scope requests
- [ ] Integration tests: 20 bookings created, amended and cancelled correctly
- [ ] Handover tested end to end (call transfer, message capture, notification)
- [ ] Monitoring and alerts configured; error workflow active
- [ ] Usage caps and alerts at 80% of allowance

## Launch

- [ ] Client UAT sign-off (written)
- [ ] Staff training delivered; quick-reference guide left behind
- [ ] Go-live (staged: chat → voice → campaigns)
- [ ] Hypercare schedule set (daily review for 2 weeks; check-ins on day 3 and day 10)
- [ ] Remaining 50% of setup invoiced

## Day 30

- [ ] First monthly report sent
- [ ] Results review meeting held
- [ ] Testimonial and case study permission requested
- [ ] Referral ask made
- [ ] Health score recorded
